# 03 · 平台适配与功能矩阵

> **出稿前必读**。同一需求在三平台上写法不同——先查本文件再动笔。

## 一、三平台写法差异（总表）

| 维度 | 飞象老师 | 讯飞星光 2.0 | 通用大模型（豆包/DeepSeek/Gemini） |
|---|---|---|---|
| 生成机制 | 输入需求后**自动完成**需求分析→教学设计→配色→交互→布局 | 语音/文字口述，**会先反问确认**需求再生成 | 直接生成，不补全，写给什么是什么 |
| 提示词长度 | **可相对精简**（平台会补全） | 中等，套公式 | **必须写全 9 要素** |
| 关键写法 | 点明"用什么方式表达抽象概念"+"用途"；善用"做同款"+上传素材 | 「角色+任务+要求+效果」；口语化、场景化；被反问时补学情与用途 | 强调"单文件 HTML、CSS/JS 内联、完整输出、无需联网" |
| 独有能力 | 数据回收、教育应用(3.0)、素材上传、命题组题 | 数据回收接学情、一键转教学应用、家校事务、生态素材联通 | 完全可控、可离线、可二次开发 |
| 默认输出 | 未指定平台时的默认版本 | 一并输出（"两平台为主"） | 仅当用户指定，或需完全可控/离线时输出 |

## 二、飞象老师（feixianglaoshi.com）

**定位**：猿辅导出品，中小学教师专属 AI 工具；一句话生成 3D 交互动画 / 游戏化课件 / 教育应用。

**功能模块**：AI 互动课件 / AI 教学动画、AI 命题、AI 组题、AI 教案·大单元、（3.0）教育应用生成。

**写法要点**
1. 提示词可**精简**，但**学科+年级+教材版本+知识点+资源形式（动画/游戏/模拟/闯关）+ 关键交互**必须写清。
2. 点明"**表达抽象概念的方式**"（如"用可旋转 3D 模型""用滑块调参观察变化"）。
3. 明确**用途**：课堂大屏演示 / 学生自主练习 / 当堂检测（涉数据回收尤其重要）。
4. 善用"**做同款**"：资源广场找相似案例改，比从零写省力。

**参考句式**
```
请为【人教版八年级物理】的【光的折射】设计一个互动课件：左侧可拖动改变入射角，实时显示折射光线与折射角，标注法线与介质；右侧给出光路规律小结。适配教室大屏，单文件 HTML。
```

**支持的上传素材**：doc/docx/pdf/ppt/pptx/xls/xlsx/txt/csv/html/md/json、常见图片、3D 模型（glb/gltf/obj/stl），最多 20 个（以官网实时为准）。

**数据回收**：提示词里加一句"**请加入数据回收与教师看板**"，可生成"学生答题版 + 教师数据看板版"。

**导出与使用**：全屏投屏；下载独立 HTML（双击浏览器离线可用）；可插 PPT（超链接）、嵌入希沃白板、发链接给学生。

**坑**：非 K12（大学/职教）适配度低；文科史实需人工核验；动画课堂建议 1–3 分钟。

## 三、讯飞星光 2.0（sparklight.cn）

**定位**：科大讯飞出品，面向 K12 教师的"教师超级智能体"，覆盖备课—授课—评价—家校—教研全链路。

**核心能力**：H5 互动创编、数据回收接学情、生态资源联通、学生成长激励、家校协同、教师专业成长。

**写法要点**（星火大模型官方方法论高度适用）
1. **通用公式**：交代角色 + 目标任务 + 操作要求 + 输出效果（你是谁 + 做什么 + 怎么做 + 做成什么样）。
2. **角色扮演**：区分"任务执行者"与"受众"。例：❌"写一篇恐龙科普" → ✅"你是一名小学自然科学老师，用 6 岁孩子听得懂的语言写一篇恐龙科普短文"。
3. **提供背景**：含身份、要点、现状。
4. **给步骤或示例**：难描述时投喂样例让模型模仿。
5. **限定输出效果**：指定格式、文风、字数。
6. **口述三段式**：学科/学段 + 知识点/课题 + 想要的资源形式（H5 动画/互动练习/闯关游戏/组卷）。被"反问"时把学情与用途补清楚。
7. **结构化字段**（稳定输出）：`Role / Background / Profile / Skills / Goals / Workflow / Constraints / OutputFormat`。

**数据回收 / 教学应用**：H5 可一键转为教学应用并关联班级；开启"数据回收"后，学生作答与完成情况自动归档，每位学生、每道题掌握情况可视。

**坑**：英语等单科深度偏弱；"零代码 ≠ 零门槛"，内容质量须教师把关；数据安全需留意；导出格式细节**以平台实时界面为准**。

## 四、通用大模型（豆包 / DeepSeek / Gemini 等）

**适用**：追求完全可控、可离线、可二次开发；或平台做不了的特殊定制。

**写法要点**
1. **必须写全 9 要素**（无教育内嵌逻辑）。
2. **必写技术约束**："输出单个 HTML 文件，CSS/JS 内联，完整输出不截断，无需联网，双击可运行"。
3. 明确"完整可运行代码"（`<!DOCTYPE html>` 到 `</html>`），并在 JS 中注释可改区。
4. 生成 HTML 比纯文本慢、消耗高，**警惕"视觉花哨陷阱"**，内容清晰优先。
5. 数据回收 / 教学应用类需求**不要**交给通用大模型裸做（无现成后端），除非用户接受自行部署。

## 六、同一需求 · 三平台写法对照（示例：勾股定理）

**飞象老师版**（精简）
```
为人教版八年级数学《勾股定理》设计一个互动课件：拖动顶点改变两直角边，三块正方形面积实时显示并验证 a²+b²=c²，提供割补证明动画。适配教室大屏。
```

**讯飞星光版**（角色+任务+要求+效果）
```
你是一位初中数学老师。请为八年级《勾股定理》生成一个 H5 交互动画，让学生拖动直角边顶点时，以两直角边和斜边为边的三块正方形面积实时更新并验证 a²+b²=c²。要求：含割补法证明动画，界面简洁适合投屏，题目步骤清晰。
```

**通用大模型版**（写全 9 要素）
```
【角色】你是资深初中数学教师 + 前端工程师
【学情】人教版八年级，基础中等，已学三角形与正方形面积
【目标】通过操作—猜想—归纳，理解并验证勾股定理，突破面积法证明
【交互】拖动顶点改变两直角边，三块正方形面积实时显示 a²/b²/c² 并验证 a²+b²=c²，提供割补证明动画
【视觉】蓝白两色，正文≥24 号，适配大屏
【技术】输出单个 HTML 文件，CSS/JS 内联，无需联网
【输出】完整可运行代码（<!DOCTYPE html> 到 </html>），JS 注释标出可改区
【验收】① 面积随拖动实时正确 ② 有三块正方形着色 ③ 有重置按钮
```
