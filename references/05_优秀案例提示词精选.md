### 课堂互动小工具"通用开发要求"（开发底座模板）
> 用于制作任意课堂互动小工具（点名、转盘、倒计时、分组、抽奖等）的前置"通用要求"。作者说明该提示词具备"记忆功能"，第一个工具告知 AI 后，后续工具无需重复填写，可统一风格、音效、数据持久化与多班级管理规范。
```
你是一个课堂互动工具开发专家。请帮我制作一个课堂互动小工具，要求如下：
【基本要求】1. 使用 React（JSX）开发，最终同时提供：一个 .jsx 文件（用于在线预览）、一个独立 .html 文件（可直接双击在浏览器中打开，无需安装任何软件）2. HTML 版本需要引入 CDN 资源（React、ReactDOM、Babel），确保离线也能使用 3. 界面语言为中文
【视觉风格】1. 明亮、活泼、清新的浅色主题（适合课堂投屏）2. 背景：暖色渐变，带柔和彩色光斑漂浮动画 3. 卡片：纯白圆角卡片 + 轻盈阴影 4. 配色：彩虹色系 5. 字体：标题 + 正文 6. 动画：入场、弹入、标题渐变 7. 禁止使用深色/暗黑主题
【音效要求】1. 使用 Web Audio API 合成音效（不依赖外部音频文件）2. 包含操作节奏音、胜利号角、蓄势鼓点 3. 音效要有变化
【数据持久化（HTML版本）】1. 使用 localStorage 自动保存所有数据 2. 关闭浏览器后再打开数据不丢失 3. 每次操作后显示"已自动保存"提示 4. 提供"导出数据备份"（JSON）5. 提供"导入数据"功能
【学生名单输入方式】1. 提供文本框直接输入与表格上传（.xlsx/.xls/.csv，SheetJS 解析）两种方式 2. 自动过滤序号与表头关键词 3. 两种方式可混合、自动合并去重 4. 每个名字显示为彩色标签，可单独删除、可一键清空
【多班级管理】1. 顶部班级切换栏，支持创建/切换/删除 2. 每班独立保存 3. 提供管理面板查看人数与使用统计
【PPT 配套】1. 同时生成配套 .pptx（3页：封面/功能亮点/启动页含 HTML 超链接）2. PPT 与 HTML 同文件夹，放映时点击按钮跳转
【特效】1. 结果揭晓时满屏纸屑撒花 2. 关键元素脉冲光环 3. 按钮 hover 放大 + 阴影
```
〔🟡 教程示例，来源：璟慧智能《OpenClaw 帮我做了 6 款课堂小工具，提示词全公开》〕

### 小学古文八大游戏《囊萤夜读》（8 组提示词）
```
第一关 感知关（听音识韵）— 古文盲盒
请扮演一位温婉的古代私塾先生，用舒缓、富有节奏感的语调朗读《囊萤夜读》，背景音乐使用轻柔的古琴曲，语速放慢，适合三年级小学生跟读。
第二关 剧场关（古文剧场）— 光影重现
请生成一段3分钟的2D水墨风动画短片，讲述晋代少年车胤夏天用白色薄绢做成袋子装几十只萤火虫来照明的故事。画面要突出夜晚的静谧和萤火虫微光下少年专注读书的神情，不要出现现代物品。
第三关 诵读关（古文诵读）— 声控萤火虫
请作为古文朗读评测助手，精准识别小学生的朗读发音，特别是"囊（náng）""练（liàn）""数（shù）"等易错字。根据发音准确度和停顿节奏给出1-100的评分，并给出鼓励性语音反馈。
第四关 字词关（字词学习）— 字词消消乐
请为三年级学生解释"练囊盛萤"中的"练"字。用通俗易懂的语言解释它在古文中指"白绢"，并生成一个古代白绢袋的卡通图片。再设计一个有趣的连线配对游戏，包含"恭勤不倦"的释义。
第五关 解密关（文意理解）— 古今侦探社
请扮演一位幽默的古代侦探，不要直接翻译《囊萤夜读》。通过提问引导学生自己发现车胤家贫、无灯油的困境。当学生回答正确时，给予"大侦探"称号；回答错误时，给出"看看课文第一句"的提示。
第六关 感悟关（感悟心得）— 时空信箱
请扮演一位知心大哥哥/大姐姐。当小学生分享学习《囊萤夜读》的感受时，不要讲大道理。请结合现代生活，肯定他们的感悟，并生成一句温暖的鼓励语（20字以内），用于制作明信片。
第七关 赏析关（趣味故事）— 故事盲盒
请用生动、像讲睡前故事一样的口吻，讲述车胤后来通过努力成为大官的故事，以及"孙康映雪"的典故。语言要充满童趣，时长控制在2分钟左右。
第八关 实战关（真题演练）— 智慧擂台
请基于《囊萤夜读》出三道适合三年级的选择题。第一题考查"恭勤不倦"的字义；第二题考查课文内容理解；第三题考查精神内涵的迁移。请附带通俗易懂的解析。
```

## 四 · 案例改造法（三步复用）

1. 选一个最接近的案例（本集或平台资源广场）；
2. 只改三处：**知识点、学情（年级+教材版本）、交互形式**；
3. 生成后按验收清单检查，并把改好的提示词存档，形成自己的（校级）模板库。

> ⚠️ 案例中的学科内容（尤其历史、生物、化学）生成后必须人工核验。
