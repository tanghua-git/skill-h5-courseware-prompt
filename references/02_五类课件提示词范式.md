# 02 · 五类课件提示词范式

> 本文件是技能的核心产出模板。**出稿前必读**。每类给：适用判断 → 结构范式（可复制）→ 交互/技术要点 → 多学科范例。

---

## A. 教学动画（动态模拟 / 仿真演示）

**适用**：抽象概念可视化、实验仿真、过程演示、3D 结构。

**结构范式**
```
为【学段+学科】【知识点】做一个动态演示网页：
① 主画面展示【演示对象/模型】，用【Three.js 3D / Canvas 2D / SVG】绘制；
② 提供【可调参数及范围与单位】，拖动后画面实时重绘；
③ 实时显示【关键物理/化学量】的数值与曲线；
④ 提供播放/暂停/重置按钮，支持【分步讲解】；
⑤ 单文件 HTML，CSS/JS 内联，适配教室大屏。
```

**要点**：参数必须写清"物理意义 + 范围 + 单位"；必须有播放/暂停/重置；初始条件→现象要可视化；物理量单位统一。

**范例**
- 数学·勾股定理：`拖拽顶点改变两直角边，三块正方形面积实时显示 a²/b²/c² 并验证 a²+b²=c²，提供割补证明动画，单文件 HTML，适配大屏。`
- 物理·单摆：`可调摆长 L、质量 m、初始角 θ 与阻力系数；实时显示动能、势能、机械能数值与曲线；支持暂停/继续/重置；无阻力时总机械能守恒。`
- 化学·电解水：`用 3D 展示电解水微观过程：水分子分裂为氢氧原子并重新组合，配平 2H₂O→2H₂↑+O₂↑，滑块控制进程，原子按 CPK 标准着色。`

## B. 教学游戏（游戏化练习）

**适用**：练习巩固、活跃气氛、复习闯关。

**结构范式**
```
以【故事线/主题】为背景，做【年级+知识点】的闯关游戏：
① 共【X】关，难度递进；答对前进并播放鼓励动画，答错显示错因与解析并允许重试；
② 顶部显示进度与得分，底部有"再玩一次"按钮；
③ 风格【活泼卡通】，配色鲜艳适合小学生/【专业简洁，适合中学生】；
④ 输出单个完整 HTML 文件，双击即可运行。
```

**要点**：故事线 + 关卡递进 + 即时判定 + 错因解析 + 计分/鼓励反馈；难度递增；可重玩。

**范例**
- 英语·单词：`上传【单词表】，生成【单词消消乐/贪吃蛇】游戏：图片—单词配对，答对有音效，统计正确率。`
- 语文·古诗：`以《西游记》取经之路为故事线，做六年级课内古诗词闯关：每关一首诗填空，答对进入下一关并表扬，答错给提示并允许重试。`
- 地理·复习：`做地理知识闯关：答对解锁新地点，集齐地图碎片通关。`

## C. 互动课件（多页课件）

**适用**：完整一节课、多环节讲解、承上启下的结构化课件。

**结构范式**
```
做【课题】（【学段+教材版本】）的多页互动课件：
① 共【N】页，每页一个任务，标题用动词开头（探究/验证/挑战…）；
② 结构：【情境导入】→【新知探究】→【动手操作】→【巩固练习】→【课堂小结】；
③ 每页含导航与进度指示，关键过渡页有承上启下的串词；
④ 交互：【该页具体的交互】，操作后有【反馈】；
⑤ 风格专业简洁，正文≥24 号，输出单个 HTML 文件。
```

**要点**：分页 + 每页一个任务 + 导航/进度 + 页间串词；控时长；避免"流水账"。

**范例**
- 语文·桃花源记：`第一人称探索课件：学生以渔夫身份点击前行，依次经过"发现洞口—进入村落—村民问讯—离开复寻"四场景，每处配原文句与白话解说。`
- 数学·二次函数：`6 页互动课件，含拖拽控制参数、函数图像实时变换，每页一个探究任务。`

## D. 数据回收（当堂检测 · 学情采集）

**适用**：当堂检测、想知道谁做错、正确率统计。**仅飞象老师 / 讯飞星光支持**，通用大模型需自行实现后端。

**结构范式**
```
做【知识点】当堂检测，并加入数据回收：
① 生成两个页面："学生答题版"与"教师数据看板版"；
② 学生版：【X】道题（题型含【选择/填空/拖拽排序】），作答后联网提交；
③ 教师端实时查看：谁交了、各题正确率、高频错题，客观题附可视化统计看板；
④ 支持"再来一组"。
```

**要点**：必须双端（学生版+教师版）；联网提交；看板要能看"谁交/正确率/高频错题"。**输出时必须注明"该功能仅飞象/星光支持"，并附隐私合规提醒。**

**范例**
- 物理·电学：`做"电学当堂检测"，学生答题版 + 教师看板版，实时看谁交了、正确率与高频错题。`
- 英语·语法：`宾语从句当堂检测，10 道选择题，学生提交后教师端出正确率与高频错题看板。`

## E. 教学应用（可分享的小工具 / 系统）

**适用**：错题收集、随机点名、分组、积分评价、数据收集与统计。**飞象 3.0 / 星光强项**（有独立链接、可迭代、可保存）。

**结构范式**
```
做一个【功能】应用：
① 学生【操作，如提交错题照片/文字】；
② AI/系统自动【处理，如按知识点分类、总结错因】；
③ 教师按【维度，如知识点】查看统计结果；
④ 要求：独立访问链接、支持多人使用、数据可保存可导出、可迭代优化。
```

**要点**：独立链接 + 多人使用 + 数据持久化 + 可导出；点明"谁用、做什么、结果怎么看"。

**范例**
- 错题收集：`做一个错题收集应用：学生提交错题照片/文字，AI 自动按知识点分类并总结错因，老师按知识点查看统计与高频错题，支持导出。`
- 课堂评价：`做一个课堂评价计分网页：粘贴班级名单，可对个人/小组一键加减分，实时显示积分排行榜，数据本地保存不丢失。`

## 附 · 场景扩展库（15 类，按需取用）

当需求不落在上述 5 类主型时，可用下列更细的场景模板：

| 场景 | 范式句（替换【】） |
|---|---|
| 动态模拟 | 用【Three.js/Canvas】做【知识点】动态模拟：【可调参数】，实时显示【关键量】，播放/暂停/重置 |
| 闯关游戏 | 以【故事线】做【年级+知识点】闯关：答对前进、答错给错因，共【X】关 |
| 当堂检测 | 做【知识点】当堂检测：【X】道题，即时判对错给解析，顶部进度得分 |
| 评价积分 | 做课堂评价计分网页：【粘贴名单】，一键加减分，实时排行榜，数据本地保存 |
| 听写/朗读 | 做词语听写小工具：【上传词语表】，点击按序朗读，每词间隔【X】秒，可重播、可显示答案 |
| 3D 展示 | 用 Three.js 做【细胞/地球圈层/分子结构】3D 模型：360° 旋转、逐层拆解，点击显示说明 |
| 交互时间轴 | 做可点击时间轴梳理【历史事件】：点击节点显示时间/事件/意义，可拖动 |
| 情境剧情 | 以【文本】为蓝本做第一人称剧情互动：通过对话/选择推进，不同选择触发不同反馈 |
| 知识卡片 | 把【知识点】做成可翻转闪卡：正面问题、背面答案解析，可打乱、可标记"已掌握" |
| 图表可视化 | 用【ECharts/Chart.js】做【主题】交互图表：【输入/随机】数据实时更新，可切换图表类型 |
| 错题整理 | 做错题整理应用：学生录入错题，AI 按知识点分类总结错因，教师查看统计，支持导出 |
| 虚拟实验记录 | 做【物理/化学】虚拟实验应用：调【变量】观察结果，记录数据，生成报告，教师看汇总 |
| 语音互动 | 做英语跟读练习：显示句子，点击播放标准朗读并跟读，标注重音节奏 |
| 抽签/分组 | 做随机点名抽签网页：【粘贴名单】，点击抽取带动画，不重复抽取，支持随机分组 |
| 单页美化 | 把【第 X 页】优化为【知识卡片式布局】，突出【核心结论】，字号加大到【28】号以上 |
