## 一、五大设计理念（提示词的"质量宪法"）

写通用版提示词时，把这 5 条作为开头的设计理念段（可整段复制）：

1. **学情为本**：技术为教学服务。交互设计必须符合学生认知规律，辅助教师引导，绝不盲目炫技。
2. **深度互动**：思考可视化。将解题或探索过程通过点击、拖拽、划线等操作实时呈现，反馈即时醒目。**杜绝沦为毫无交互的"PPT 播放器"**。
3. **大屏极简**：专为教室大屏/白板设计。剔除无关装饰，确保最后一排学生清晰可见。
4. **低门槛操作**：师生"零学习成本"。拒绝按钮堆砌，符合直觉，极力防误触。
5. **价值升华**：不设"唯一标准答案"拦截。提供实时数据辅助（如数量统计），鼓励"非完美"试错与规律探索。

> 第 5 条是本文件最独特的教学主张：游戏/探究类课件的判分逻辑应是"反馈+引导"而非"拦截"，尤其适合探究型、实验型课题。

## 二、四层严格技术规范（A→D，附可直接粘贴话术）

### A. 架构与依赖层

| 规范 | 要点 | 提示词话术（可直接粘贴） |
|---|---|---|
| 单文件交付 | 所有 CSS/JS 内联，开箱即用 | "输出单一 .html 文件，所有 CSS/JS 内联，保证双击即可运行，代码完整不截断" |
| 按需生态借力 | 只引需要的可靠 CDN，不引大图 | "可按需通过 CDN 引入：图形图表用 ECharts/Chart.js，3D 用 Three.js，表格用 SheetJS/Handsontable，文档解析用 Mammoth.js，PDF 用 jsPDF/PDF.js" |
| 状态持久化 | localStorage 缓存进度，防刷新丢失 | "用 localStorage 缓存学生的交互进度与答题记录，刷新页面后不丢失" |

### B. 视觉与排版层

| 规范 | 要点 | 提示词话术 |
|---|---|---|
| **一屏全显** | 绝对响应式，**严禁出现上下左右滚动条** | "采用绝对响应式布局，主体内容一屏完整显示，严禁出现任何滚动条" |
| 高对比大字号 | 极简 UI，去渐变背景 | "极简 UI，不使用渐变背景，超大字号、高对比配色，最后一排学生清晰可见" |
| **绝对精准对齐** | 覆盖类标记（划线/打叉/圈定）必须与底层目标居中对齐 | "所有覆盖类标记（划线、打叉、圈选）必须用 CSS translate / flex / 绝对定位实现，确保与底层文字或图形绝对居中对齐，不得错位" |

### C. 交互与多端层

| 规范 | 要点 | 提示词话术 |
|---|---|---|
| **双轨事件** | 绝不可仅限鼠标；PC 与触屏同时支持 | "所有交互必须同时监听并处理鼠标事件（click/mousedown）与触屏事件（touchstart/touchmove），确保教室触控大屏与平板均可操作" |
| **精准防误触（Hitbox）** | 只把核心内容区设为触发目标 | "仅将核心内容区（如文字中心、图形本体）设为触发热区，严禁把大容器整块绑定连划/拖拽事件，防止误触" |
| 外设扩展 | 支持翻页笔 | "适度监听键盘事件（方向键、空格、回车），支持教师用翻页笔快捷翻页与操作" |

### D. 逻辑与数据层

| 规范 | 要点 | 提示词话术 |
|---|---|---|
| **双向可逆** | 所有标记可撤销 | "所有标记/交互必须支持撤销（再次点击或双击取消上一步操作）" |
| 智能状态管理 | 状态流转严密 | "状态流转须严密：例如在'隐藏答案'状态下新增的标记，必须自动继承隐藏状态，不破坏整体显隐逻辑" |
| **动态教学锚点** | 界面边缘的极简数据反馈面板 | "在界面左侧或顶部设计一个极简数据反馈面板（如'剩余 X 个''已答对 X 题'），随操作实时更新，驱动课堂进程" |
| 本地资源 I/O | 读取本地素材 | "如需外部素材，支持通过 `<input type=\"file\">` 读取本地图片、音视频或 JSON 文件" |

## 三、离线优先 与 CDN 的取舍原则（重要，防矛盾）

默认承诺"无需联网"与"按需引 CDN"并不冲突，按下表决策：

| 场景 | 策略 | 提示词写法 |
|---|---|---|
| 教室网络不稳 / 要拷给学生带走 | **纯离线**：不引任何外部依赖，图形用原生 Canvas/SVG 手绘 | "不使用任何外部依赖与 CDN，全部原生 HTML/CSS/JS 实现，离线双击可运行" |
| 功能必须（3D、复杂图表、公式渲染）且教室有网 | **引 CDN 但显著标注** | "通过 CDN 引入 Three.js（需联网加载）；若加载失败显示文字提示" |
| 拿不准 | 默认纯离线，并在交付说明里留一句 | "如需 3D 等增强效果，可回复'允许联网'切换 CDN 版本" |

> 经验：K-12 课堂课件 90% 的交互用原生 Canvas/SVG/JS 足够，CDN 只留给 3D（Three.js）、数据图表（ECharts）、公式（KaTeX）三类硬需求。

## 四、五步执行工作流（嵌入提示词，让 AI 按序思考）

把下面这段放进通用版提示词末尾，强制大模型"先设计后编码"，显著降低返工率：

```
请严格按以下顺序思考与输出：
1. 需求解构：提炼学科知识点，确定核心互动方式与"教学数据锚点"（反馈面板显示什么）；
2. MVP 构建：用原生 HTML/CSS/JS 搭建无滚动条的一屏自适应框架；
3. 交互打磨：落实双端兼容（鼠标+触屏）、精准对齐、防误触触发区；
4. 价值注入：按选配锚点接入对应能力（如 localStorage 持久化、容错可逆逻辑、动态数据反馈面板）；
5. 最终交付：输出结构清晰、注释详尽的单文件完整 HTML 代码。
```

## 五、技术增强块（两层结构：必带 3 条 + 按类型选配）

> ⚠️ 防指令过载原则：大模型约束越多，核心教学逻辑越容易被稀释（见 01 §六"指令过载排查"）。**禁止 7 条全塞**——通用锚点 3 条必带，再按课件类型从选配表加 1–3 条。

### 5.1 通用锚点（凡通用版必带，3 条）

```
【技术增强要求】
1. 一屏全显：绝对响应式布局，严禁出现任何滚动条；超大字号、高对比、无渐变背景，适配教室大屏。
2. 双端交互：所有操作同时支持鼠标（click/mousedown）与触屏（touchstart/touchmove），触发热区仅限核心内容本体，防误触。
3. 精准对齐：覆盖类标记（划线/圈选/打叉）用 CSS 绝对定位与底层目标居中对齐，不得错位。
```

### 5.2 按类型选配（从课件类型对应行取 1–3 条追加）

| 课件类型 | 选配锚点 | 话术（可直接粘贴） |
|---|---|---|
| 教学动画 | 数据面板 | "界面【左侧/顶部】设极简数据面板，实时显示【关键量数值】，随操作同步更新" |
| 教学动画（多环节） | 键盘/翻页笔 | "监听键盘方向键/空格/回车，支持翻页笔控制播放暂停与步骤切换" |
| 教学游戏 | 可逆容错+计分面板 | "答错给引导性反馈而非终止，不设唯一答案拦截；界面设得分/进度面板实时更新；所有标记可再次点击撤销" |
| 教学游戏 | 进度持久化 | "用 localStorage 保存闯关进度与最高分，刷新不丢失" |
| 互动课件（多页） | 进度持久化 | "用 localStorage 保存学习进度（已学页码/答题记录），刷新后可续学" |
| 互动课件（多页） | 键盘/翻页笔 | "监听键盘方向键/空格，支持翻页笔翻页" |
| 教学应用 | 数据持久化（此类必配） | "用 localStorage 持久化全部业务数据，刷新/重开不丢失，并提供导出功能" |
| 教学应用（涉素材） | 本地资源 I/O | "支持通过 <input type=\"file\"> 读取本地图片、音视频或 JSON 文件" |

> **持久化按需原则**：一次性演示类（看一遍就过的动画）不强制 localStorage；仅当"进度/积分/业务数据"对教学有价值时才启用。

### 5.3 状态流转严密性（涉及显隐/开关类交互时追加）

"状态流转须严密：例如在'隐藏答案'状态下新增的标记，必须自动继承隐藏状态，不破坏整体显隐逻辑；所有开关可再次点击复原。"

## 六、技术验收点（与 06 的 8 条清单互补）

通用版课件交付后，追加验收这 6 条：

- [ ] **一屏无滚动**：窗口缩放到 1080P/4K 均无滚动条，内容完整；
- [ ] **触屏可用**：用手指（或模拟触屏）点/拖全部生效，无鼠标独占交互；
- [ ] **防误触**：点空白区/容器边缘不触发操作；
- [ ] **可撤销**：任意标记可再点取消，连续操作后状态不紊乱；
- [ ] **刷新不丢**（若选配了持久化）：操作一半刷新页面，进度恢复（localStorage）；
- [ ] **数据面板在动**：锚点面板数字随操作实时变化。
