# 06 · 迭代话术与验收合规

> 出稿后附加"迭代话术"与"验收提醒"时读本文件。

---

## 一、迭代话术库（可直接复制给教师）

| 目的 | 话术 |
|---|---|
| 追问式修改 | "把动画速度调慢一倍，并增加重置按钮。" |
| 局部修改 | "只改第 3 页：换成 3 道选择题，答错显示解析。" |
| 追加约束 | "上次字号太小，这次正文统一 28 号，每页不超过 6 行。" |
| 换表达/补示例 | "参照这个例子重新做一遍：【贴一个样例】。" |
| 简化重试 | "先只保留核心功能，跑通后再逐步加特效。" |

## 二、常见误区（生成前避坑）

### 提示词端 7 种
| 误区 | 后果 | 解法 |
|---|---|---|
| 一句话指令 | 跑偏、返工 | 套 9 要素骨架 |
| 不写学情 | 超纲或过浅 | 写清教材版本+班级水平+前置知识 |
| 不写视觉规范 | 投屏后排看不清 | 贴格式要求：字体/字号/配色/每页行数 |
| 不写结构 | 内容像流水账 | 分板块、标时长、给过渡串词 |
| 不要求完整输出 | 只得片段/截断 | "输出完整单文件 HTML，不要截断" |
| 忽略交互 | 退化成 PPT 播放器 | 写明"学生能做什么+操作后反馈" |
| 直接复制教材 | 信息堆砌、无设计感 | 转化为活动/问题/图示 |

### 使用端三大坑
1. **格式乱，投屏糊** → 先贴格式要求再生成。
2. **配图版权风险** → 用可商用素材库（Pixabay/Unsplash）或注明"AI 生成"。
3. **水土不服** → 必须"喂学情"（本校真实水平 + 教材版本）。

---

## 三、生成失败 / 效果不对怎么办

- **指令过载**：先简化指令只留核心需求，跑通后再逐条加回。
- **网络类报错**：切换网络重试。
- **追问式迭代**：同对话内补要求。
- **局部修改**：只改有问题的页/段，不推倒重来。
- **"做同款"起步**：找相似案例改造，成功率最高。
- **换表达**：同一需求换说法、补示例（Few-shot）再试。
- **多模型对比**：同一提示词在飞象/星光/豆包各跑一遍，选最贴合的。
- **血泪教训**：不要迷信第一版；内容清晰 > 外观华丽；动画服务教学（课堂播放 1–3 分钟）。

## 四、交付前验收清单（8 条）

- [ ] **科学正确**：知识点逐条核对，无科学性错误、无过时表述；
- [ ] **交互有效**：滑块/拖拽/点击真的生效，参数变化同步联动；
- [ ] **大屏可读**：字号够大、每屏信息不过载，投影后排能看清；
- [ ] **反馈完整**：答对答错有即时反馈，错题给出正确答案与解析；
- [ ] **可逆可控**：有重置/撤销，动画可暂停、可调速度；
- [ ] **离线可用**：下载后双击能打开，不依赖网络（如讲义需要）；
- [ ] **轻量流畅**：图片已压缩、未误插大视频导致卡顿；
- [ ] **备用方案**：课件只是辅助，准备好教案/板书，防设备故障。

## 五、合规红线（务必遵守）

依据《中小学生成式人工智能使用指南（2025 年版）》与《教师生成式人工智能应用指引（第一版）》：

1. **育人环节须教师主导**：价值观引导、道德教育、情感培养、心理支持不得交由技术替代；
2. **必须核查再使用**：AI 生成内容可能有科学性错误、过时信息或偏见，未经审查不可直接用于教学；
3. **原创环节须教师主导**：选题、核心设计、数据解读、论点撰写等不得把 AI 生成内容直接当作个人成果；
4. **小学阶段**：原则上不让学生独立使用生成式 AI，确需使用须教师或监护人指导；
5. **数据合规**：**禁止将学生个人信息、考试试题等敏感数据输入 AI**；
6. **著作权**：未经授权不得用 AI 复制、传播他人作品；配图优先用可商用素材或注明"AI 生成"。

**隐私提醒**：使用平台"数据回收"功能时，学生姓名、成绩等属个人信息，应遵守学校与平台的数据管理要求，不对外扩散。

## 六、存疑标注原则（技能内置）

- 平台积分/额度/导出格式等不确定信息，一律附「以平台实时界面为准」。
- 不引用未经核实的宣传性数据（如"XX 万教师""效率提升 X%"）。
- 案例来源须可追溯，标注可信度（官方/一线/教程/媒体/待核对）。
